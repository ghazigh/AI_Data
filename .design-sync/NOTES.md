# design-sync notes — @datalith/ui (Confluence)

- Component `FAQ` is an all-caps acronym: the converter's PascalCase filter drops it. Fixed via `.design-sync/overrides/dts.mjs` fork (declared in `cfg.libOverrides`) + `componentSrcMap.FAQ` pin. Keep both when re-syncing.
- Preview `.tsx` files MUST export **function components** (`export const X = () => (...)`) — element exports (`export const X = (<div/>)`) render an empty root with no error (the card harness only mounts `typeof === 'function'` exports).
- Tokens are inlined into `dist/styles.css` by `design-system/scripts/copy-assets.mjs` at package build. Do NOT use `tokensGlob` — it only resolves through `tokensPkg` in node_modules, which never matches a self-package.
- Fonts wire via `extraFonts: ["dist/fonts/fonts.css"]` (self-hosted woff2 under `dist/fonts/`, generated by `design-system/scripts/fetch-fonts.mjs` — network fetch from Google Fonts at build time).
- Every full-width section (Navbar, Hero, LogoStrip, FeatureGrid, StatBand, Steps, Quote, PricingTable, FAQ, CTABand, Footer) plus Button uses `cardMode: "column"` in `cfg.overrides` — Button's multi-cell rows overflowed the grid otherwise.
- Base CSS resets in `design-system/src/styles.css` are `:where()`-wrapped (zero specificity) so component variant colors win on anchor-rendered Buttons. Don't "simplify" them back to `:is()` — that reintroduced black-on-black CTA labels.
- Previews wrap every cell in `<div className="dl-root">`; components rendered without it lose background/font/reset context (belt-and-suspenders resets exist for lists/links only).
- Converter invocation (repo root): `node .ds-sync/package-build.mjs --config .design-sync/config.json --node-modules design-system/node_modules --entry ./design-system/dist/index.js --out ./ds-bundle`.
- Known render warns: none. (GRID_OVERFLOW on Button resolved via cardMode column.)

## Re-sync risks

- `scripts/fetch-fonts.mjs` fetches woff2 from Google at package-build time — offline builds keep the committed `src/fonts/` files; only `npm run fonts` needs network.
- Playwright + chromium live in `.ds-sync/node_modules` (gitignored) — reinstall per clone (`npm i esbuild ts-morph @types/react playwright` in `.ds-sync/` + `npx playwright install chromium`); the `.design-sync/node_modules` symlink (`ln -sfn ../.ds-sync/node_modules .design-sync/node_modules`) must be recreated per clone for the dts.mjs fork.
- Grades are campaign-local (`.design-sync/.cache/`) — carry-forward across machines comes from the uploaded `_ds_sync.json` anchor.
- Built with Node 23 / npm; the dev shell is zsh (unquoted `$var` does NOT word-split) and `grep` is aliased to ugrep.
- `.design-sync/overrides/dts.mjs` is a fork of `lib/dts.mjs` — on re-sync, diff against the bundled version and merge upstream changes.
